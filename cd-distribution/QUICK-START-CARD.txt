SYSTEM REQUIREMENTS:
--------------------
Minimum:
  • CPU: Dual-core
  • RAM: 2GB
  • Storage: 1GB free
  • OS: Windows 10/11, Ubuntu 20+, macOS 11+

Option A: Python 3.9+ and Node.js 18+
Option B: Docker Desktop (easiest)

INSTALL IN 3 STEPS:
-------------------

OPTION 1: DOCKER (Recommended - 2 minutes)
  1. Open terminal in this CD/folder
  2. Run: docker-compose up -d
  3. Open: http://localhost:3000

OPTION 2: WINDOWS (5-10 minutes)
  1. Double-click: setup-windows.bat
  2. Wait for installation
  3. Browser opens automatically

OPTION 3: LINUX/MAC (5-10 minutes)
  1. Open terminal
  2. Run: chmod +x setup-linux.sh && ./setup-linux.sh
  3. Open: http://localhost:3000

TROUBLESHOOTING:
----------------
• Port in use? → Change ports in docker-compose.yml
• Can't login? → Run: python create_admin.py
• Database error? → Delete fognetx.db and run migrate.py
• Need help? → See TROUBLESHOOTING.md on this CD
