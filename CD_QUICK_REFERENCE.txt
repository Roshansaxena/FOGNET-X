========================================
FOGNET-X - CD Burning Quick Reference
========================================

STEP 1: PREPARE FILES
---------------------
1. Create folder: FOGNET-X-CD
2. Copy these files:
   ✓ fognet-x-source.zip (entire project)
   ✓ README.txt (instructions below)
   ✓ docker-compose.yml
   ✓ firmware/esp8266_complete_node.ino

STEP 2: BURN TO CD (Windows)
-----------------------------
1. Insert blank CD-R
2. Open File Explorer → DVD Drive
3. Drag FOGNET-X-CD contents to disc
4. Click "Burn to disc"
5. Select 16x speed
6. Wait for completion
7. Verify files

STEP 3: TEST
------------
1. Eject and re-insert CD
2. Open README.txt
3. Extract fognet-x-source.zip
4. Run: docker-compose up -d
5. Open: http://localhost:3000
6. Login: admin / admin123

FOGNET-X - Fog Computing IoT Platform
======================================

QUICK START:
1. Install Python 3.8+ (python.org)
2. Install Docker Desktop (docker.com)
3. Extract fognet-x-source.zip
4. Open terminal in extracted folder
5. Run: docker-compose up -d
6. Open: http://localhost:3000
7. Login: admin / admin123

FEATURES:
✓ Real-time IoT monitoring
✓ Fog/Cloud orchestration
✓ Live sensor data
✓ Device dashboard
✓ Automated alerts

REQUIREMENTS:
- Python 3.8+
- Docker Desktop
- 4GB RAM
- 2GB disk space

========================================

WHAT TO EXCLUDE FROM CD:
------------------------
✗ node_modules/ (too large)
✗ __pycache__/ (cache files)
✗ .git/ (version control)
✗ *.db (created on first run)
✗ logs/ (not needed)
✗ venv/ (recreate locally)

FILE SIZES:
-----------
fognet-x-source.zip  ~50MB (compressed)
Full project         ~200MB (uncompressed)
CD capacity          700MB
DVD capacity         4.7GB

BURNING SPEEDS:
---------------
CD-R:  16x or 24x (recommended)
DVD-R: 8x or 16x (recommended)
Slower = More reliable!
